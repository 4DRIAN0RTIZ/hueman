# Quickstart

> Examples assume the `hueman` command is installed (see [Install](install.md)).
> From a checkout without installing, use `python3 -m hueman` instead.

## 1. Minimal config

Create a directory and write a sample config with `hueman init`
(it also accepts the default path, `~/.config/hueman/config.yaml`, without
`--config`):

```sh
mkdir -p ~/dotfiles/theme
hueman --config ~/dotfiles/theme/hueman.config.yaml init
```

That file ships many targets; for this quickstart keep only two (or replace it
with this), each with an explicit `outputs` list:

```yaml
state_file: "~/.config/hueman/current"   # where the active palette is remembered

targets:
  kitty:
    template: kitty.conf.j2     # packaged template
    palette_key: kitty          # palette section passed to the template
    mode: overwrite             # rewrite the whole file
    outputs:
      - "~/.config/kitty/theme.conf"

  tmux:
    template: tmux.conf.j2
    palette_key: tmux
    mode: overwrite
    outputs:
      - "~/.config/tmux/theme.conf"
```

More options (patch, reload, `palette_dirs`) in
[Configuration](configuration.md) and [Targets](targets.md).

## 2. List palettes

```sh
hueman --config ~/dotfiles/theme/hueman.config.yaml list
```

```text
arctic-ice
autumn
catppuccin-latte
catppuccin-mocha
copperwave
...
```

## 3. Dry run

```sh
hueman --config ~/dotfiles/theme/hueman.config.yaml set catppuccin-mocha --dry-run
```

```text
[DRY RUN] would write ~/.config/kitty/theme.conf
[DRY RUN] would write ~/.config/tmux/theme.conf
```

## 4. Apply

```sh
hueman --config ~/dotfiles/theme/hueman.config.yaml set catppuccin-mocha
```

```text
INFO: Generated: ~/.config/kitty/theme.conf
INFO: Generated: ~/.config/tmux/theme.conf
INFO: Active theme: catppuccin-mocha
```

## How to tell it worked

```sh
hueman --config ~/dotfiles/theme/hueman.config.yaml status
```

```text
Active theme: catppuccin-mocha
Available palettes: arctic-ice, autumn, catppuccin-latte, catppuccin-mocha, ...
Configured targets: 2 (2/2 outputs present on disk)
```

(The real palette line lists all 25 packaged ones; shortened here.)
And the generated file:

```sh
head -5 ~/.config/kitty/theme.conf
```

```text
# Generated by hueman — do not edit by hand; overwritten on every `hueman set`.
foreground            #cdd6f4
background            #1e1e2e
selection_foreground  #1e1e2e
selection_background  #f5e0dc
```

## If something fails

An unknown palette exits 1 and lists the ones available:

```text
ERROR: Palette not found: no-such. Available: arctic-ice, autumn, ...
```

(The real list includes every palette.) More cases in
[Troubleshooting](troubleshooting.md).
